# OnlyUs 💗 bubudubu

Private couple space for long-distance love.

**Soft romantic pink/purple theme** • Real-time synchronized music • Chat • Virtual hugs

## Features (MVP)

- 🎵 **Synced Music** – Search any song or paste YouTube link. Both hear it at the same time.
- 💬 Live chat
- 🤗 Virtual Hug / Kiss / Miss You reactions with floating animations
- 👀 Online presence
- Soft romantic UI (mobile-friendly)

## How to run locally

```bash
cd onlyus
pip install -r requirements.txt
python app.py
```

Open http://localhost:5000

1. Enter your name
2. Room code: `bubudubu` (same for both)
3. Enjoy together

## Deploy

Works great on Render / Railway / Heroku / any VPS.

Set `SECRET_KEY` environment variable for production.
